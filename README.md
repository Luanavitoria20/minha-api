## 🎀 Sobre o projeto

O **Minhas Tarefas** é uma aplicação web que permite organizar atividades de forma simples e prática. 💕

Com ele, você pode adicionar tarefas, marcar as concluídas e excluir as que não são mais necessárias.

## ✨ Funcionalidades

- 📝 Adicionar novas tarefas
- 📋 Visualizar todas as tarefas
- ✅ Marcar tarefas como concluídas
- 🗑️ Excluir tarefas
- 💾 Armazenar informações em um banco de dados

## 🛠️ Tecnologias utilizadas

| 💻 Tecnologia | ✨ Utilização |
|---|---|
| 🟢 Node.js | Executar o backend |
| 🏗️ NestJS | Construir a API |
| 💙 TypeScript | Desenvolver o backend |
| 🔷 Prisma ORM | Acessar o banco de dados |
| 🗃️ SQLite | Armazenar as tarefas |
| 🎨 HTML | Estruturar a página |
| 💅 CSS | Estilizar o site |
| ⚡ JavaScript | Adicionar interatividade |
| 🐙 Git e GitHub | Versionar e compartilhar o projeto |

## 🚀 Como executar

**1. 📥 Baixe o projeto**

```bash
git clone https://github.com/Luanavitoria20/minha-api.git
```

**2. 📂 Entre na pasta**

```bash
cd minha-api
```

**3. 📦 Instale as dependências**

```bash
npm install
```

**4. ⚙️ Configure o arquivo `.env`**

Na pasta principal, configure a variável do banco de dados:

```env
DATABASE_URL="file:./dev.db"
```

**5. 💜 Inicie a API**

```bash
npm run start:dev
```

A API estará disponível em:

🔗 http://localhost:3000

**6. 🌸 Abra o site**

Com a API rodando, abra o arquivo `index.html` no navegador.

## 🔌 Rotas da API

| Método | Rota | Descrição |
|---|---|---|
| 📋 `GET` | `/tasks` | Listar tarefas |
| ➕ `POST` | `/tasks` | Criar uma tarefa |
| ✅ `PATCH` | `/tasks/:id/concluir` | Concluir uma tarefa |
| 🗑️ `DELETE` | `/tasks/:id` | Excluir uma tarefa |
